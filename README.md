## 👋 About Me

I'm **Rodas Awgichew**, a final-year Information Systems student and **Frontend & Full-Stack Developer** based in Addis Ababa, Ethiopia.

I enjoy turning real-world problems into practical web applications — from polished user interfaces to APIs, databases, authentication, and deployment.

My main strength is frontend development, but I've been expanding deeper into backend engineering and system development with Python.

### What I work with

- 🎨 **Frontend:** React, Next.js, TypeScript, JavaScript, Tailwind CSS
- ⚙️ **Backend:** Python, FastAPI, Django, Django REST Framework
- 🗄️ **Databases:** PostgreSQL, SQL, SQLite
- 🔐 **Backend Systems:** REST APIs, JWT authentication, OAuth, role-based access
- 🚀 **Infrastructure:** Docker, Redis, Alembic, SQLAlchemy
- 🤖 **AI:** LLM APIs, RAG systems, AI-powered application concepts
- 🛠️ **Tools:** Git, GitHub, Postman, Vite, VS Code

I'm especially interested in building **SaaS products, marketplaces, business platforms, and AI-powered applications**.
